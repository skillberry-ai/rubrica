# Rubrica documentation

An index of the current documentation, grouped by what you are trying to do.
Each line names the question that document answers.

## Start here

- [`getting-started.md`](getting-started.md) — How do I run Rubrica end to end,
  from a clone of this repository to an emitted suite, stage by stage or in one
  step with the orchestrator?

## Concepts

- [`concepts/pipeline.md`](concepts/pipeline.md) — What stages does a run go
  through, in what order, and what does each one do?
- [`concepts/pipeline-diagram.html`](concepts/pipeline-diagram.html) — The same
  pipeline, drawn: where do the fan-outs open and their barriers fall, which
  gates does a human hold, and what does each stage leave on disk? Open it in a
  browser. Generated by `scripts/render-pipeline-diagram.py`; edit that, not
  the page. The README's own drawing is the same run at a newcomer's altitude,
  generated the same way by `scripts/render-readme-diagram.py`.
- [`concepts/artifact-contract.md`](concepts/artifact-contract.md) — What is
  the rule that governs how a stage is dispatched, and what are the two
  layers that check what it writes?
- [`concepts/glossary.md`](concepts/glossary.md) — What does this term mean,
  precisely, and what actually produces or consumes it?
